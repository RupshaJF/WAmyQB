AI তাফসীর/প্রশ্নোত্তর সহকারী — সেটআপ (একবারই করতে হবে, সম্পূর্ণ ফ্রি, কোনো কার্ড লাগে না)
================================================================================

১) https://aistudio.google.com এ যান, যেকোনো Google অ্যাকাউন্ট দিয়ে সাইন-ইন
   করুন (কোনো কার্ড/বিলিং তথ্য চাইবে না) → বাম পাশে "Get API key" →
   "Create API key" → নতুন key কপি করুন।

২) আপনার Vercel প্রজেক্ট ড্যাশবোর্ড → Settings → Environment Variables →
   নতুন variable যোগ করুন:
     নাম:   GEMINI_API_KEY
     মান:   (১ নং ধাপে কপি করা key)
   এরপর প্রজেক্ট রি-ডিপ্লয় করুন (Vercel এর "Redeploy" বাটন)।

৩) FIREBASE_SERVICE_ACCOUNT env variable আগে থেকেই থাকার কথা
   (api/send-reset-email.js ফিচারের জন্য বসানো হয়েছিল) — এটাই এই
   ফিচারও ব্যবহার করে দৈনিক প্রশ্ন-সংখ্যা গুনতে। যদি এটা এখনো না
   বসানো থাকে: Firebase Console → Project settings → Service accounts
   → Generate new private key → ডাউনলোড হওয়া JSON-এর পুরো কন্টেন্ট
   এক লাইনে Vercel env variable হিসেবে বসান (নাম: FIREBASE_SERVICE_ACCOUNT)।

৪) নতুন কোনো npm install লাগবে না — root package.json ইতিমধ্যে
   firebase-admin যোগ করা আছে, Vercel deploy করার সময় নিজে থেকেই
   install হয়ে যাবে।

৫) সব ফাইল Vercel-এ push/deploy করুন। এরপর অ্যাপে ঢুকে যেকোনো আয়াতের
   নিচে "✨ AI তাফসীর" বাটনে চাপ দিয়ে, বা হ্যামবার্গার মেনু থেকে
   "AI তাফসীর সহকারী" ট্যাপ করে পরীক্ষা করুন।

কেন Vercel-ই লাগবে (Firebase Hosting/অন্য স্ট্যাটিক হোস্টিং দিয়ে হবে না):
   /api/ai-tafsir একটা সার্ভারলেস ফাংশন (Node.js) — Gemini API key
   গোপন রাখতেই এই ফাংশনের ভেতরে বসানো, সরাসরি ব্রাউজারে না রেখে।
   স্ট্যাটিক হোস্টিং এই ধরনের সার্ভার-সাইড কোড চালাতে পারে না।

দৈনিক প্রশ্নের সীমা বদলাতে চাইলে:
   api/ai-tafsir.js ফাইলে DAILY_LIMIT = 20 লাইনটা খুঁজে সংখ্যা বদলান।
   (ফ্রি Gemini কোটা দৈনিক ~১৫০০ রিকোয়েস্ট, সব ইউজারের মধ্যে ভাগ হয় —
   তাই খুব বেশি বাড়ানোর আগে ইউজার-সংখ্যা মাথায় রাখুন।)

নোট: Google-এর ফ্রি টায়ারের শর্তে বলা আছে, এই টায়ারে পাঠানো প্রশ্ন/উত্তর
Google তাদের মডেল উন্নত করতে ব্যবহার করতে পারে (paid টায়ারে এটা হয় না)।
সাধারণ ধর্মীয় প্রশ্নোত্তরের জন্য এটা সমস্যা না, শুধু জানিয়ে রাখা হলো।
