AI তাফসীর/প্রশ্নোত্তর সহকারী — সেটআপ (একবারই করতে হবে, সম্পূর্ণ ফ্রি, কোনো কার্ড লাগে না)
================================================================================

১) https://aistudio.google.com এ যান, যেকোনো Google অ্যাকাউন্ট দিয়ে সাইন-ইন
   করুন (কোনো কার্ড/বিলিং তথ্য চাইবে না) → বাম পাশে "Get API key" →
   "Create API key" → নতুন key কপি করুন।

২) আপনার Vercel প্রজেক্ট ড্যাশবোর্ড → Settings → Environment Variables →
   নতুন variable যোগ করুন:
     নাম:   GEMINI_API_KEY
     মান:   (১ নং ধাপে কপি করা key)
   এরপর প্রজেক্ট রি-ডিপ্লয় করুন (Vercel এর "Redeploy" বাটন)।

৩) FIREBASE_SERVICE_ACCOUNT env variable লাগবে — এই ফিচার এটা দিয়ে
   সাইন-ইন যাচাই ও দৈনিক প্রশ্ন-সংখ্যা গোনে। যদি এটা এখনো না বসানো
   থাকে: Firebase Console → Project settings → Service accounts →
   Generate new private key → ডাউনলোড হওয়া JSON-এর পুরো কন্টেন্ট এক
   লাইনে Vercel env variable হিসেবে বসান (নাম: FIREBASE_SERVICE_ACCOUNT)।

৪) নতুন কোনো npm install লাগবে না — root package.json ইতিমধ্যে
   firebase-admin যোগ করা আছে, Vercel deploy করার সময় নিজে থেকেই
   install হয়ে যাবে।

৫) সব ফাইল Vercel-এ push/deploy করুন। এরপর অ্যাপে ঢুকে যেকোনো আয়াতের
   নিচে "✨ AI তাফসীর" বাটনে চাপ দিয়ে, বা হ্যামবার্গার মেনু থেকে
   "AI তাফসীর সহকারী" ট্যাপ করে পরীক্ষা করুন।

কেন Vercel-ই লাগবে (Firebase Hosting/অন্য স্ট্যাটিক হোস্টিং দিয়ে হবে না):
   /api/ai-tafsir একটা সার্ভারলেস ফাংশন (Node.js) — Gemini API key
   গোপন রাখতেই এই ফাংশনের ভেতরে বসানো, সরাসরি ব্রাউজারে না রেখে।
   স্ট্যাটিক হোস্টিং এই ধরনের সার্ভার-সাইড কোড চালাতে পারে না।

ফিচারটা "কাজ করছে না" হলে যা যা চেক করবেন (ক্রমানুসারে):
--------------------------------------------------------------------------------

১) Vercel Dashboard → Settings → Environment Variables এ গিয়ে চোখে দেখে
   নিশ্চিত হোন GEMINI_API_KEY এবং FIREBASE_SERVICE_ACCOUNT দুটোই
   আছে, এবং দুটোতেই Production টিক দেওয়া আছে (শুধু Preview/Development
   এ টিক থাকলে লাইভ সাইটে কাজ করবে না)।

২) env variable যোগ/পরিবর্তনের পর অবশ্যই নতুন করে Redeploy করতে হবে —
   পুরনো ডিপ্লয়মেন্ট নতুন variable আপনাআপনি দেখতে পায় না। Vercel
   Dashboard → Deployments → সর্বশেষ ডিপ্লয়মেন্টের পাশে "..." → Redeploy।

৩) FIREBASE_SERVICE_ACCOUNT এর মান হতে হবে ডাউনলোড হওয়া JSON ফাইলের
   *পুরো* কন্টেন্ট (curly brace { থেকে } পর্যন্ত সব), এক টুকরায়, কোনো
   অংশ বাদ না দিয়ে। আংশিক পেস্ট হলে বা কোনো অক্ষর মিসিং হলে ফিচারটা
   কনফিগার-না-করা অবস্থায় থেকে যাবে।

৪) Vercel Dashboard → আপনার প্রজেক্ট → Logs ট্যাবে গিয়ে "ai-tafsir" লিখে
   সার্চ করুন — কোন ধাপে আসলে কী এরর হচ্ছে (ভুল API key, মডেল না পাওয়া
   যাওয়া, কোটা শেষ, ইত্যাদি) এখানে স্পষ্ট লেখা থাকবে।

৫) মডেলের নাম নিয়ে এখন চিন্তা করার দরকার নেই — api/ai-tafsir.js এ এখন
   একাধিক মডেলের একটা লিস্ট (GEMINI_MODELS) আছে, একটা ব্যর্থ/বন্ধ হয়ে
   গেলে পরেরটা নিজে থেকেই ট্রাই হয়। গুগল ভবিষ্যতে মডেলের নাম আবার
   বদলালে/বন্ধ করলেও, লিস্টের অন্তত একটা মডেল চালু থাকা পর্যন্ত ফিচারটা
   কাজ করতে থাকবে। (বর্তমান gemini-2.5-flash ১৬ অক্টোবর ২০২৬-এ বন্ধ হয়ে
   যাচ্ছে বলে গুগল ঘোষণা দিয়েছে — তাই এখন এটা তালিকার শেষে ব্যাকআপ
   হিসেবে রাখা, আর নতুন ও বেশি দিন টিকবে এমন মডেল সামনে রাখা হয়েছে।)

দৈনিক প্রশ্নের সীমা বদলাতে চাইলে:
   api/ai-tafsir.js ফাইলে DAILY_LIMIT = 20 লাইনটা খুঁজে সংখ্যা বদলান।
   (ফ্রি Gemini কোটা প্রতিটা মডেলের জন্য আলাদা, দৈনিক কয়েকশ' থেকে
   কয়েক হাজার রিকোয়েস্ট পর্যন্ত — সব ইউজারের মধ্যে ভাগ হয়, তাই খুব বেশি
   বাড়ানোর আগে ইউজার-সংখ্যা মাথায় রাখুন।)

(নতুন) অ্যাকাউন্ট ছাড়া (অতিথি) সীমা:
   এখন সাইন-ইন ছাড়া প্রতি ডিভাইসে সর্বমোট GUEST_LIMIT = 2 টা প্রশ্ন করা
   যায় (দৈনিক না, একবারই) — এরপর চালিয়ে যেতে অ্যাকাউন্ট/সাইন-ইন লাগবে।
   বদলাতে চাইলে api/ai-tafsir.js ফাইলে GUEST_LIMIT লাইনটা খুঁজে সংখ্যা
   বদলান, আর js/ai-tafsir.js ফাইলে AIT_GUEST_LIMIT_DISPLAY (শুরুতেই
   UI-তে দেখানো সংখ্যা, দুটো একই রাখতে হবে) — দুই জায়গাতেই কমেন্টে এই
   কথাটা লেখা আছে।

নোট: Google-এর ফ্রি টায়ারের শর্তে বলা আছে, এই টায়ারে পাঠানো প্রশ্ন/উত্তর
Google তাদের মডেল উন্নত করতে ব্যবহার করতে পারে (paid টায়ারে এটা হয় না)।
সাধারণ ধর্মীয় প্রশ্নোত্তরের জন্য এটা সমস্যা না, শুধু জানিয়ে রাখা হলো।
