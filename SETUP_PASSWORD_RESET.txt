পাসওয়ার্ড রিসেট ইমেইল — সেটআপ (একবারই করতে হবে)
================================================================================

সমস্যা যা ঠিক করা হয়েছে: আগে "পাসওয়ার্ড ভুলে গেছেন" চাপলে বা প্রোফাইল
পেজ/মোডাল থেকে রিসেট-লিঙ্ক চাইলে "কিছু একটা সমস্যা হয়েছে, আবার চেষ্টা
করুন" ছাড়া আর কিছুই দেখাতো না। কারণ ছিল: অ্যাপ তখনো সরাসরি Firebase-এর
নিজস্ব sendPasswordResetEmail() ব্যবহার করছিল, যেটা Firebase Console-এর
"Customize action URL" সেটিং-এর উপর নির্ভরশীল — সেই Console UI-টাই বাগি
(এটা api/send-reset-email.js ফাইলে আগে থেকেই লেখা ছিল, কিন্তু কোনো
বাটন/ফর্ম থেকে এটা কখনো ব্যবহারই করা হতো না)। এখন js/auth.js ও
js/profile-view.js — রিসেট-লিঙ্ক পাঠানোর তিনটা জায়গাতেই — সরাসরি এই
api/send-reset-email.js এন্ডপয়েন্টে POST করে, যেটা Firebase Admin SDK
দিয়ে নিজে থেকেই সঠিক লিঙ্ক বানায় (বাগি Console সেটিং স্পর্শ না করেই) আর
Gmail SMTP দিয়ে পাঠায়।

--------------------------------------------------------------------------------
নতুন যা যা লাগবে (Vercel Dashboard → Settings → Environment Variables →
Production ও Preview দুই জায়গাতেই):
--------------------------------------------------------------------------------

১) FIREBASE_SERVICE_ACCOUNT
   আগে থেকেই থাকার কথা (api/ai-tafsir.js ফিচারের জন্যও লাগে) — না থাকলে
   SETUP_AI_TAFSIR.txt এর ধাপ ৩ দেখুন।

২) GMAIL_USER
   যে Gmail অ্যাকাউন্ট থেকে রিসেট-ইমেইল পাঠানো হবে (যেমন:
   yourapp@gmail.com)।

৩) GMAIL_APP_PASSWORD
   সাধারণ Gmail পাসওয়ার্ড এখানে বসাবেন না — এটা আলাদা একটা ১৬-অক্ষরের
   "App Password"। বানাতে:
   ক) ওই Gmail অ্যাকাউন্টে ২-স্টেপ ভেরিফিকেশন চালু থাকতে হবে (না থাকলে
      আগে myaccount.google.com → Security → 2-Step Verification চালু করুন)
   খ) myaccount.google.com/apppasswords এ যান → একটা নাম দিন (যেমন:
      "quranview-reset") → Generate → ১৬-অক্ষরের যে পাসওয়ার্ড দেখাবে সেটাই
      এখানে বসান (স্পেস ছাড়া বা সহ, দুটোই কাজ করে)

৪) env variable যোগ/পরিবর্তনের পর অবশ্যই নতুন করে Redeploy করতে হবে —
   পুরনো ডিপ্লয়মেন্ট নতুন variable আপনাআপনি দেখতে পায় না। Vercel
   Dashboard → Deployments → সর্বশেষ ডিপ্লয়মেন্টের পাশে "..." → Redeploy।

৫) কোনো নতুন npm install লাগবে না — root package.json এ nodemailer আর
   firebase-admin দুটোই আগে থেকেই আছে।

--------------------------------------------------------------------------------
সেটআপ শেষে যা যাচাই করবেন:
--------------------------------------------------------------------------------

১) api/send-reset-email.js ফাইলে actionCodeSettings.url এ
   'https://quranview.vercel.app/index.html' লেখা আছে — এটা আপনার আসল
   ডোমেইন কিনা একবার চোখে দেখে নিশ্চিত হোন; ডোমেইন বদলে গেলে এখানেও বদলে
   দিতে হবে।

২) "পাসওয়ার্ড ভুলে গেছেন" থেকে একটা টেস্ট ইমেইল পাঠিয়ে দেখুন — ইমেইল না
   এলে Vercel Dashboard → আপনার প্রজেক্ট → Logs ট্যাবে "send-reset-email"
   লিখে সার্চ করুন, ঠিক কোন ধাপে কী এরর হচ্ছে সেখানে স্পষ্ট লেখা থাকবে।

৩) ইমেইলের লিঙ্কে ক্লিক করলে সরাসরি অ্যাপের ভেতরেই ("নতুন পাসওয়ার্ড দিন"
   স্ক্রিন) খোলা উচিত, Firebase-এর কোনো আলাদা পেজে না।
